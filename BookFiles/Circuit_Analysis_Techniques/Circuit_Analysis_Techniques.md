# Circuit Analysis Techniques
Most circuits are not a single voltage source connected to a single resistor. Real-life circuits are complicated! The main idea of circuit analysis is to simplify circuits' appearance or representation to make them easier to analyze. 

The first few methods that we will explore involve creating equivalent circuits to simplify the appearance of more complicated looking circuits. The last two methods will involve transforming the circuits into the frequency domain to make our analysis simpler to solve mathematically.
